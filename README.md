## API Documentation

The Employee Prediction API is built using FastAPI and serves
predictions from a saved Random Forest machine learning model.

### Technologies
- FastAPI
- Uvicorn
- Pydantic
- Pandas
- Scikit-learn
- Joblib
- Pytest
- Postman

### Run the API

Activate the virtual environment and install the dependencies:

```bash
python -m pip install -r requirements.txt
